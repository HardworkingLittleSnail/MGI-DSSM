# BATTER-MoE 论文复现

本项目依据本目录论文 BATTER-MoE: A Sparse Mixture-of-Experts Model for Accurate and Efficient Remaining Useful Life Prediction of Lithium-Ion Batteries 实现。源码覆盖原始数据读取、异常值处理、训练集统计量归一化、滑窗样本、模型、训练、一步预测、RUL 换算和十次独立实验汇总。

## 快速运行

先安装依赖：

```powershell
pip install -r requirements.txt
```

运行单次端到端检查：

```powershell
python run_experiment.py --dataset nasa --smoke-test
python run_experiment.py --dataset tju --smoke-test
```

论文协议默认运行十个随机种子：

```powershell
python run_experiment.py --dataset nasa
python run_experiment.py --dataset tju
```

输出位于 `outputs/<dataset>/`，包括每个种子的最佳权重、完整预测轨迹和均值/标准差汇总。当前目录没有 GOTION 数据；补充对应 CSV 后可运行：

```powershell
python run_experiment.py --dataset gotion --data-root <GOTION目录>
```

每个 GOTION CSV 需以 Cell01、Cell02、Cell03 开头，并有 `capacity`、`discharge_capacity` 或 `q` 容量列。

## 输入输出

- 模型输入：`[batch, lookback, channels]`。
- NASA/GOTION：单变量容量序列，容量按额定容量 `C/C0` 归一化。
- TJU：17 个逐循环健康指标；16 个非容量特征使用仅从训练窗口拟合的 Min-Max 统计量，容量特征与目标均使用 `C/C0`。
- 模型输出：下一循环的归一化容量标量 `[batch]`。
- RUL：从指定 SP 开始，在基于真实历史窗口生成的一步预测序列中寻找首次低于 EOL 阈值的位置，不做自回归长时滚动。

## 论文数据划分

| 数据集 | 训练/验证电池 | 测试电池 | 窗长 | Patch | EOL | SP |
|---|---|---|---:|---|---:|---|
| NASA | B0006/B0007/B0018 | B0005 | 16 | 2/4/8 | 70% | 50/90 |
| GOTION | Cell02/Cell03 | Cell01 | 64 | 8/16/32 | 80% | 450/750 |
| TJU | CY25-2/CY25-3 | CY25-1 | 64 | 4/8/16 | 70% | 200/400 |

本地 TJU 默认把 `CY25-05_1-#1/#2/#3.csv` 映射为论文的 CY25-1/2/3。若需要复现实验条件的其他三重复组，可传 `--tju-condition CY25-05_2` 或 `CY25-05_4`；但这将不再是默认论文映射。
