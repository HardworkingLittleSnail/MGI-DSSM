# MGI-DSSM 可用于引言的贡献点

> 文档用途：凝练可直接写入引言末段的贡献声明。下述判断以当前 `mgi-physics` 实现为准，也不预设尚未完成的对比实验结论。

## 1. 总体判断

本文的核心思路不是直接预测容量，而是先由历史放电观测反演有效状态，再预测状态的跨循环演化，最后由预测状态求得下一循环容量。

正式引言采用“一总三分”的四条结构：第一条概括MGI-DSSM，后三条分别对应状态反演、状态预测和容量计算，即

$$
\text{放电观测}
\rightarrow
\text{有效状态}
\rightarrow
\text{跨循环状态转移}
\rightarrow
\text{电压响应与截止容量}
$$

后三条是总体框架的三个关键环节。多尺度特征、GRU和复合损失属于具体实现，不再单独列为贡献。

## 2. 可直接放入引言的贡献表述

本文的主要贡献概括如下：

1. **提出宏观引导的深度状态空间模型（MGI-DSSM）。** 本文将跨循环容量预测视为部分可观测退化系统中的状态推断与演化问题。从这一角度，容量不是一个简单的标量，而是内部退化状态在给定放电工况和截止条件下的外部表现。

2. **将宏观观测反演为有效退化状态。** (宏观观测反映的是电池退化的外部响应，难以直接反应容量变化。)故我们将这些观测转化为在电压响应与容量计算中具有明确作用的有效状态，可为跨循环预测提供统一且受物理约束的学习对象。具体而言，模型通过电极平衡和电压响应关系匹配历史放电曲线，反演有效锂库存、正负极有效容量和阻抗状态。

3. **构建物理约束的跨循环状态演化模型。** (现有物理关系能够描述给定状态下的放电响应，却难以给出状态在循环之间的演化规律。)模型保留已知的状态—响应关系，仅由神经网络学习尚未明确的跨循环状态变化，从而避免数据模型重复拟合已有物理知识，并保留对非线性退化轨迹的适应能力。具体而言，模型联合状态水平、相邻变化和长短期趋势预测下一循环的相对状态变化，再通过有界乘性更新保持状态为正并限制单步跃迁。

4. **状态预测与容量输出的物理一致性。** 模型依据预测状态及相应的放电边界条件生成下一循环容量，将容量输出纳入状态空间模型的物理观测过程，使预测状态、放电响应与容量结果保持一致，并为最终预测提供可追溯的状态依据。

上述五维状态均指由有限整电池观测辨识得到的有效代理状态，不等同于唯一可辨识的材料级参数；第三条不施加硬单调约束，仅表示状态更新能够响应局部非单调波动，不代表退化机理具有可逆性。

## 3. 更凝练的引言版本

如果引言篇幅有限，可使用下面这一版：

> 本文的贡献主要体现在四个方面。第一，我们将跨循环容量预测视为部分可观测退化系统中的状态推断与演化问题，并据此提出MGI-DSSM，使容量预测由标量外推转化为对内部退化过程的状态空间建模。第二，我们将宏观观测反演为在电压响应与容量计算中具有明确作用的有效退化状态，为跨循环预测提供统一且受物理约束的学习对象。第三，我们将数据学习集中于难以显式描述的跨循环退化动力学，使已知物理关系与未知状态演化各自承担明确的建模任务。第四，我们依据预测状态及放电边界条件生成下一循环容量，使预测状态、放电响应与容量结果保持物理一致。

## 4. 与相邻工作的差异应如何界定

| 相邻工作及其贡献写法             | 其主要创新对象                                                    | 本文应强调的窄化差异                                                                                         |
| -------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| PatchFormer                      | 用patch级与特征级注意力捕获容量序列的全局趋势、局部依赖和容量恢复 | 本文不把注意力或多尺度时序编码本身作为核心，而强调由曲线反演的方程作用状态及其物理容量生成路径               |
| BatteryMFormer                   | 从老化工况、跨电池轨迹模式和SOC局部信号三个层级学习早期退化表示   | 本文的状态不是一般学习表示，而是在简化电极平衡和电压方程中承担明确变量角色的有效状态                         |
| MSTEA-Net                        | 以特征子集、多尺度编码和双物理正则组成复合损失                    | 本文的主要差异不是“使用更多物理损失”，而是让物理关系进入状态构造和最终容量生成路径                           |
| BattNN                           | 按ECM设计网络前向结构，使循环内建模过程遵循物理结构               | 因此不能宣称本文首次把物理嵌入网络结构；本文更具体地研究历史曲线反演、跨循环状态转移与首次截止容量之间的闭合 |
| Wang等的physics-informed SOH模型 | 由充电片段提取通用特征，并用经验退化与状态空间方程学习SOH动力学   | 本文不以统计特征直接估计SOH，而以完整放电观测构造有效状态，并由未来状态的截止事件产生绝对容量                |
| BATTER-MoE                       | 通过稀疏专家路由和多尺度时序模块适应异质退化轨迹                  | 本文不以条件计算或更大模型容量作为创新，而以物理状态中介和输出闭合提高预测链的可审计性                       |

上述论文的贡献段落具有共同写法：先指出一个明确技术对象，再说明为解决该对象设计了什么机制，最后用实验验证其作用。本文也应遵循“对象—机制—可验证收益”的结构，而不写成模块名清单。

## 6. 不建议写成贡献的内容

- **“首次提出物理引导的电池预测模型”**：已有BattNN、physics-informed SOH模型及多种PIML框架，不能成立。
- **“首次将物理嵌入神经网络结构”**：BattNN等工作已经明确采用物理结构化前向传播。
- **“GRU和多尺度趋势特征”**：这些是支撑状态转移的实现机制，单独看属于常规设计，应归入第三条贡献。
- **“在CALCE、NASA和TJU上进行了实验”**：这是证据范围，不是方法创新；三个数据集分别训练也不能写成zero-shot泛化。
- **“五维状态是真实退化机理参数”**：没有独立材料测量和全局可辨识性证明，只能称有效整电池代理状态。
- **“可逆退化建模”**：当前实现只是允许局部双向状态更新，不能上升为电化学退化可逆机理。
- **“更准确、更高效或更具泛化性”**：只有在强基线、Persistence、严格多步、端到端计时和多数据集实验完成后，才能加入相应结果。
- **“曲线监督是一项已验证贡献”**：在确认曲线损失对可训练参数产生有效梯度并完成消融之前，只能写成训练设计。

## 7. 引言结果收束句：仅在证据完成后使用

实验范围不再列为第五项贡献。如果最终完成三个数据集的统一架构实验、严格无未来观测的递归预测、完整闭合验证和端到端效率比较，可在四条贡献之后增加一句结果概述：

> 最后，我们在CALCE、NASA和TJU三个具有不同采集协议与化学先验的数据集上，采用相同的反演—转移—解码主体架构进行跨电池评估，并结合强Persistence基线、严格递归预测、物理闭合和端到端成本分析，从预测精度、长期稳定性、物理一致性和计算代价四个层面验证该框架。

该句只有在对应实验全部完成后才能使用；无论实验是否完整，正式贡献始终保持“一总三分”的四条结构。
